About this card: El Niño–Southern Oscillation (ENSO, measured by the Relative Oceanic Niño Index, RONI) and the Indian Ocean Dipole (IOD, measured by the Dipole Mode Index, DMI) are national-scale climate indices, not administrative post measurements. In the CDI they enter as one flag for the whole country (ENSO 20%, IOD 10%).

About the data

CDI
Combined Drought Index from FAO Timor-Leste, from 0 to 1. Higher values mean climate drivers point more strongly to agricultural drought.
Rainfall anomaly (CHIRPS)
Rainfall for the observed month compared with normal, from CHIRPS satellite rainfall. Below zero is drier than normal.
Soil moisture anomaly (SM)
Soil moisture for the observed month compared with normal. Below zero is drier than normal.
Vegetation index (VI)
Vegetation condition for the observed month. Lower values mean less healthy vegetation; the map uses the vegetation condition guide of the PNG El Niño platform (below 0.35 high stress, 0.35–0.50 moderate, 0.50–0.65 watch, above 0.65 lower stress).
Rainfall forecast (fcRain3)
Forecast rainfall for the next three months compared with normal. Below zero is drier than normal.
ENSO, IOD
National flags for El Niño–Southern Oscillation and the Indian Ocean Dipole, as given in the CDI file.
Map classes
The CDI map uses the seven bands and colours of the FAO CDI map for Timor-Leste; the other maps use five classes (four for the vegetation index). All limits are fixed and shown in the map legend, so that months can be compared.

FAO methodology

About the Combined Drought Index (CDI)

The Combined Drought Index (CDI) is used by FAO in Timor-Leste to assess agricultural drought severity and to support anticipatory action. It follows published research (Isaev E, Yuave N, Inape K, Jones C, Dawa L & Sidle RC, 2024, Agricultural Drought-Triggering for Anticipatory Action in Papua New Guinea, Water 16, 2009) and is computed for each of the 65 administrative posts of Timor-Leste, every month, from free and open data sources.

IndicatorSourceFlag ruleWeightColumn in the CDI file
ENSO (RONI 3.4)NOAA0.5 if alert, 1 if declared20%ENSO
Indian Ocean Dipole (DMI)NOAA0.5 if alert, 1 if declared10%IOD
Present rainfall (SPI-1)CHIRPS3, Climate Hazards Center (UCSB)0.5 if −0.5 ≤ SPI < 0, 1 if SPI < −0.520%CHIRPS
Present soil moisture (SMAPI)ERA5-Land, ECMWF0.5 if 5–15% below normal, 1 if more than 15% below20%SM
Present vegetation health (VHI)FAO ASIS0.5 if VHI < 0.4, 1 if VHI < 0.310%VI
Forecast rainfall (SPI-3)ECMWF SEAS 5.10.5 if −1 ≤ SPI < 0, 1 if SPI < −120%fcRain3

Combination: these six flags are combined into a weighted sum from 0 to 1. ENSO and IOD are national climate indices, so their flags are the same for every administrative post; the other four are measured for each administrative post. The CDI shows where climate drivers are converging strongly enough to warrant action. It does not by itself confirm crop failure or food insecurity: field verification and livelihood and market evidence determine the scale and type of response.

For every administrative post in the — file, these flag rules and weights give exactly the CDI value provided by FAO.
